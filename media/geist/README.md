# Geist webfonts

These variable WOFF2 files come from [Vercel's Geist Font project](https://github.com/vercel/geist-font/tree/ef2597cfc42f4797676df105517ccc0a1cfa6569), discovered through the [SEESAW Geist listing](https://www.seesaw.website/websites/geist). The [original OFL-1.1 and copyright notice](OFL.txt) accompany the files.

Select only the styles the project uses. Copy OFL.txt with the font files and include it when distributing the fonts. For the normal sans weight range, serve the file under the project's origin and use `@font-face` with `font-family: Geist`, `font-weight: 100 900`, `font-style: normal` and `font-display: swap`.
