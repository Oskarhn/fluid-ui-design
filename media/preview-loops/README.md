# Light and depth loops

Four original 8-second Canvas loops. The 960 × 540 H.264 files run at 24 fps and carry no audio. The source material is the project's own geometry, shapes and tonal studies. The files and their first-frame posters are distributed under this repo's [MIT license](../../LICENSE).
