# Design references

Start with the page's job and the strongest evidence the project can show. Select one reference below for the main composition. When the brief calls for a second pattern, borrow a supporting interaction that can coexist with the first without competing for attention.

| Project and available evidence | Reference | Main interaction |
| --- | --- | --- |
| Physical hardware with photos, a model, or a dimensioned illustration | [Industrial product reveal](industrial-product/DESIGN.md) | One exploded view tied to a meaningful part |
| An app or product with a workflow worth showing | [Product walkthrough](product-walkthrough/DESIGN.md) | A stable product frame or alternating in-use media |
| A catalog with strong editorial photography | [Editorial image index](editorial-index/DESIGN.md) | A sortable index tied to a specific image |
| A studio with finished work and client permission to show it | [Motion portfolio](motion-portfolio/DESIGN.md) | A low-cost project preview followed by a case study |
| A configuration demo with a fixed set of comparable options | [Spatial selector](spatial-selector/DESIGN.md) | Button-driven focus, with a shallow sense of depth |
| Abstract ambient motion that belongs to the brand | [Procedural background](procedural-background/DESIGN.md) | A bounded canvas layer and a static fallback |
| A multi-step application with a meaningful submit-to-next-state moment | [Form to workspace](form-to-workspace/DESIGN.md) | A fast state change anchored by an element that persists |
| A product with distinct visual specimens or custom typography | [Interactive specimen](interactive-specimen/DESIGN.md) | Controls update the specimen in place |
| An analytics view with credible time series or measurements | [Instrument readout](instrument-readout/DESIGN.md) | Explicit metric selection and updated units |
| A playful tool with clear, legitimate example inputs | [Hands-on hero](hands-on-hero/DESIGN.md) | Try an example before leaving the first screen |
| Bold display, product grids and saturated color blocks | [Hard-grid mobile](hard-grid-mobile/DESIGN.md) | Strong grid placement and a tactile press |
| Expressive illustration with readable controls | [Hand-drawn mobile](hand-drawn-mobile/DESIGN.md) | A drawn mark tied to a value |
| Tuners, cameras, decks and physical controls | [Instrument panel on mobile](instrument-panel-mobile/DESIGN.md) | A bounded dial with a strong state marker |
| Light material, shallow depth and one dominant measurement | [Soft-surface controls](soft-surface-mobile/DESIGN.md) | A high-contrast reading in a recessed track |

Use the role names, relationships and behavior in a reference, then adapt its values and materials to the brief. Each study is an original design specification. See [source selection and capture](../design-reference-workflow.md) for working with live examples, licensed media, or MotionSites MCP.
