# Editorial image index

Use for a collection where readers compare subjects, objects or places. An individual item should justify the crop, title and metadata.

- **Composition** — repeat a consistent grid for index rows, then give a selected image space to read at about 3:2 or 4:5. Put the title before metadata. Allow the first real item into the initial viewport. On narrow screens, use one column and keep sorting close to the list.
- **Look** — use an off-white ground, dark ink and rules at 10–16% ink. Pair a restrained serif for item titles with compact metadata. Start with 52–88px for the page title and 16px for text. Use a larger image margin when a collection mixes ratios.
- **Interaction** — hover or focus may preview a row image when the image carries information. Click and Enter open the item. Keep the last selected image visible until another is ready. A 120–180ms dissolve is enough.
- **Fallback** — provide alt text describing the relevant difference between items. Keep title, date, and category available if an image is missing. Tiles link directly on touch, and detail pages offer a clear return.
- **Check** — keyboard focus never causes an involuntary navigation. Avoid changing the layout as previews decode. On mobile each item still shows enough information to choose it.

Study inputs: [SEESAW's classification and original-site links](https://www.seesaw.website/) and [Parallel Archives listing](https://www.seesaw.website/websites/parallel-archives).
