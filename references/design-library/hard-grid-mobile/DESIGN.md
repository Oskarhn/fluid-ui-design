# Hard-grid mobile

Use for bold shopfronts, launches and product indices. The supplied brutalist reference shows oversized letterforms, visible rules and sharply divided color blocks. A black-and-white technical panel suggests a useful second palette for measurements.

- **Color.** Ivory `#FFF9EE`, near-black `#171613`, pink `#FF91BB` and marigold `#FFCD3C`. Put dark ink on ivory or saturated panels. Give each task one dominant block.
- **Type.** Try Barlow Condensed ExtraBold or Archivo Black for display, system sans for controls and Geist Mono for measurements. These are proposed type choices. At 390px, start with a 46–68px display and 16px body. Wrap wide words before they clip the task label.
- **Controls.** Keep straight edges, one rule weight and a pressed offset of about 1–2px. A selected key can invert the colors and show a mark. Keep the hit region in the same place.
- **Layout.** Give the product, promise and action their own grid cells. Stack in task order on small screens. Check focus, selected-state contrast and long headings at 320px.
