# Industrial product reveal

Use this for an object whose shape, materials and assembly explain why it exists. Plan two hero views before layout: the assembled product from a useful angle, and the same product with one functional part revealed.

- **Composition** — set a 12-column grid on desktop with 48–72px gutters. Give the name, promise and primary action four columns. Let the object occupy six to seven columns with enough room around it to show the silhouette. On mobile place the promise first and keep the full object in frame before the specs.
- **Look** — graphite ink on a warm neutral ground, with a signal color taken from the actual product. Start at 64–104px for display type, 16–18px for body and 12–14px for measurement labels. Use full-width rules for specifications and align figures.
- **Sequence** — assembled view → part detail → use in context. Show what unlocks, detaches or folds through a single toggle. Keep the hero still until the user acts. Alternate between the detail and assembled positions in about 480ms.
- **Fallback** — use two approved stills or draw an original dimensioned illustration. A rigid object can use CSS planes when they communicate its form. On reduced motion, swap states instantly. Expose the associated part names in text.
- **Check** — a screenshot of either state should explain what the object is. At 390px the media cannot hide the heading or primary action.
