# Instrument readout

Use when the viewer needs to understand a real measurement, its units and why it matters. Start with one question the data answers.

- **Composition** — show the instrument or underlying process in the hero. Give the readout a separate section with one generous graph and a short row of native metric buttons. Put the latest value, its unit and sample context above the trace.
- **Look** — choose a material-derived background accent and a single signal color for the active metric. Use proportional text for prose and tabular numerals for measurements. Include ticks or captions that explain the interval.
- **Interaction** — change title, number, units, accessible summary, and graph together. Crossfade graphs with different scales. Interpolate values only when comparing states on the same scale. Reserve space for the longest unit and label.
- **Fallback** — leave one meaningful metric and its units visible if JS is unavailable. Show all controls during reduced motion and switch states instantly. Label demonstration data plainly.
- **Check** — click then operate all metrics with the keyboard. Verify that the graph, values, announcement and selected control agree. Confirm labels wrap cleanly on a compact phone.

Study input: supplied metric comparison. Original sample components in [Motion studies](../../../blueprints/design-motion-studies.html).
