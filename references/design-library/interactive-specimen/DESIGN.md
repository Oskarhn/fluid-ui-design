# Interactive specimen

Use when the value of the product is visible through changes in a single specimen, such as a font, material, filter or texture.

- **Composition** — let the specimen take 60–70% of the width. Place named controls in one rail and preserve the specimen's baseline as a setting changes. Below 768px, put the controls beside or above their result with no sticky obstruction.
- **Look** — give the specimen one uncluttered surface and use numeric labels only for actual values. Keep controls at 14–16px with sufficient contrast. A thin divider is enough between areas.
- **Interaction** — reflect changes continuously when they are cheap. Keep output values intelligible in units. Ship presets that show meaningful limits and a reset that restores the initial state. Avoid moving focus when the specimen updates.
- **Fallback** — offer an actual output sample or screenshot with a caption if the renderer fails. Use properly labeled range inputs where a precise value is meaningful. A static reduced-motion mode still responds to controls.
- **Check** — test extreme values, load failure and narrow screens. Look for clipped text or a changed specimen size that moves surrounding controls.
