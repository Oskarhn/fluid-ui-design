# Procedural background

Use when a quiet moving field reinforces the subject, such as measured drift, reflected light or slow material flow. Pick a spatial relationship between the media and foreground before choosing the effect.

- **Composition** — assign the high-contrast text region before drawing. Keep activity in the opposite half or outer region. Choose a stable poster with the same contrast at both desktop and mobile crops.
- **Look** — choose a base, one accent and a transitional tone. Start with solid or gently textured edges that flow into the page ground. A focal subject should come from project media where possible.
- **Motion** — project a few lines, particles or lit regions at low speed. Localize any pointer response to a bounded area and use a decaying displacement. Use one animation loop, cap DPR and pause rendering when offscreen or hidden.
- **Fallback** — ship a still frame for reduced motion and a CSS color surface when graphics initialization fails. For approved video, use a local poster and codec-tested sources; handle playback rejection with a still.
- **Check** — compare initial, midway, poster and mobile frames for text contrast. Load the main action and meaningful text before loading the effect. A background effect never captures pointer events from foreground controls.

Study inputs: [MotionSites animated backgrounds](https://motionsites.ai/backgrounds) and the motion concept from [Interactive Pixel Water on Layers](https://layers.to/layers/cmwrvznz60008s00lbaqp6wxz-interactive-pixel-water).
