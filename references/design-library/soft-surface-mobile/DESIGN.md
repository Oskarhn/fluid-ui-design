# Soft-surface mobile controls

Use a quiet frame around one measurement or adjustment. The supplied neumorphic reference shows near-continuous pale surfaces, a raised dial, concentric rings and a saturated progress accent.

- **Color.** Cool mist `#E4EBF5`, navy `#1E3045`, blue-gray `#425970` and deep green `#166143`. Give the upper left a consistent light. Reinforce the edge when embossing is subtle.
- **Type.** Use a system sans for the value and a clear adjacent unit. Tabular figures hold the width while the value changes.
- **Geometry.** Nest a shallow track with a protruding center. Derive radius and inset as a pair. The control outline and keyboard focus must remain visible on the light ground.
- **Input.** Keep the same hit areas and range when changing skins. Put the native slider and the decrement/increment actions near the wheel. Make the number, marker and fill tell the same story.
- **Fallback.** Use defined edges or solid fills in high contrast. Show the active value when movement or shading is reduced. Check the visual result in both bright and dim conditions.
