# Design skill coverage

Fluid UI Design combines a portable core with optional specialist lookups. Use the receiving project's brief and platform to select the reference that resolves the current design decision.

## What is integrated

| Source | Coverage and use |
| --- | --- |
| Apple Design | Selected principles for direct manipulation, responsiveness, interruption, velocity handoff, typography and accessibility are in [Apple Fluid Interfaces](apple-fluid-interfaces.md) and [Mobile interfaces](mobile-platforms.md). For a complex gesture, consult the installed Apple Design skill as well. |
| SwiftUI Pro | Selected native layout, state, accessibility and review practices are summarized in [Mobile interfaces](mobile-platforms.md). The audit used [Paul Hudson's 2.0 source](https://github.com/twostraws/SwiftUI-Agent-Skill/tree/f2920b63995263f57b3e198674e89a602efba6d2/swiftui-pro). The original is available at that revision and can be consulted on demand. |
| Awesome Design Skills | All 67 style directories are in [styles](../styles/INDEX.md). On the audited machine all 134 files from the installed reference tree had byte-identical counterparts in this repo. Select a style that serves the subject and the platform. |
| Design Taste Frontend | All nine direction-library files matched the installed source byte for byte in the local audit. The direction generator and browser inspection scripts are adapted here. The [surface finish](surface-and-finish.md) also draws on the pinned current Taste Skill revision's browser finish workflow. |
| Impeccable | [Surface decisions and finish checks](surface-and-finish.md) uses its project context, design intent and production hardening guidance for the requested surface. |
| UI Craft & Anti-AI-Slop | The repo covers its core production topics in [geometry and typography](typography-and-geometry.md), [palette studies](palettes-and-aesthetics.md), and [mobile motion](motion-mobile-and-ux-patterns.md). The [design defaults](design-defaults.md) hold project-specific preferences when a technique has competing defaults. |
| Frontend Design | The [first-build workflow](design-reference-workflow.md) applies its subject-led direction, one strong composition and visual critique. Use the installed skill for deeper art direction on a distinct web project. |
| Web Design Guidelines | The [web review checklist](web-interface-guidelines.md) and [mobile guide](mobile-platforms.md) apply accessible controls, focus, reflow and motion checks. Use the installed Vercel-backed review skill when auditing web UI. |
| MotionSites Web Builder | The [example library](../examples/INDEX.md) contains the installed 40 example briefs as adaptations, alongside media studies and recipes. Use it for media selection, deliberate composition and a phone-specific crop. |
| Stageshow | The [bundled skill](../stageshow/SKILL.md) includes examples, framing and verification for product demonstrations, including phone scenes. Use it when the request calls for a proof asset or scripted product demo. |
| Pick UI Library | [UI library picks](ui-library-picks.md) is available for choosing a missing frontend primitive. Check the project's existing implementation first. The installed skill is an explicit lookup. |

Use Figma design-to-code, Figma SwiftUI, xtool-iOS, ArtCraft/Flutter, e2e or a launch-video skill when the task involves that tool or deliverable. They support handoff, build, test or presentation work around the design. Use the platform's own component and navigation conventions in the shipped interface.

Installed file matches describe the audit on 24 November 2026. The Impeccable and upstream Taste Skill review took place on 25 November 2026. Earlier research and shipped adaptations are documented in [BACKGROUND.md](../BACKGROUND.md).
