# Website motion studies

These patterns come from recordings of public pages and clips. Browser captures show visible behavior. The implementation suggestions below are original adaptations unless linked to a licensed block. Use the timing shown as a starting point only when marked as a recommendation.

| Pattern | Visible example | Apply it to a new project |
| --- | --- | --- |
| Direct manipulation of a design specimen | [Berry Reader](https://berryreader.com/) exposes reading typography controls. [DialKit](https://www.dialkit.dev/) shows adjustable headline weight and a refraction-strength control. | Give the specimen a fixed frame. Connect a native range or named choices to one model and display its value next to it. Keep text and controls usable when the preview is still. |
| Discrete navigation for a continuous scene | [Tachyon Industrial](https://www.tachyonindustrial.com/) exposes chapter dots, including a control to jump to its third section. [Architect](https://tryarchitect.com/) gives its product variants and use cases explicit controls. | Let a chapter index coordinate camera, selected control and text. Offer buttons as an alternate input to scrolling and stop camera movement with reduced motion. |
| Replay and pause are part of media controls | [Baked](https://baked.design/) exposes a reversible motion control. [Jack & Jill](https://www.jackandjill.ai/) provides replay for its role animation and controls for stories. [Nachoz](https://nachoz.app/) provides scoped replay. | Treat replay and pause as controls on the relevant scene, preserve the poster, and pause any idle loops outside the viewport. |
| Let the visitor skip the entrance | [Parallel Archives](https://parallel-archives-main.vercel.app/) exposes a Skip intro control. | Make the landing content usable after a short entrance, then give longer sequences a direct route to the rest state. Put focus on the destination when the opening disappears. |
| Details open where the item was selected | [Framer card drawer](https://bencho.dev/finds/justyna-framer-card-drawer) is shown as a curated clip. [Source-to-dialog demo](../blueprints/transition-variants.html) is an original adaptation. | Use the source item's identity and bounds to connect the card and panel. Keep native dialog focus, close by Escape and return focus to the launcher. |
| Elastic feedback follows an authoritative value | The [volume slider](https://bencho.dev/finds/gabriell-lab-volume-slider) clip shows an expanded thumb and a yielding track. | Use one range value and a bounded lag for visual followers. Render the exact value in text and support keyboard changes. Try the [Wake slider](../blueprints/bencho/blocks/wake-slider/README.md). |
| Keep progress and motion separate | A [download progress reference](https://bencho.dev/finds/raminnasibov-download-progress) and several loader clips show compact status transitions. | Feed actual progress to a native progress element and plan complete, error and cancelled states. For a simulated action, label it as simulated. |
| Keep dense material in a stable frame | [Agent/subagent](https://bencho.dev/finds/nvc-agents-subagents) and [context-map](https://bencho.dev/finds/flohoeller-context-map) studies provide examples where linked entities have to stay recognizable as the view changes. | Use keyed nodes and a shared coordinate system for edges, group highlights and selected details. Let a focused node open a text or list representation. |

[Motion composition](motion-composition.md) contains the implementation choices and adaptation checklist. The curated clips preserve their creator attribution. The public [Bencho MIT repository](https://github.com/cabralorenzo/bencho) supplies the verified copy-in blocks.
