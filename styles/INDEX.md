# 67 Interface Design Systems & Style Guides

Each directory contains a `guidance.md` (and `DESIGN.md` where applicable) specifying typography, color tokens, surface treatments, spacing, and interaction patterns for a distinct visual direction.

Choose one direction that matches the subject's world rather than blending conflicting systems.
